# Tài liệu tham khảo (tham chiếu báo cáo)

1. NestJS. *Documentation*. https://docs.nestjs.com/ — Truy cập khi triển khai module API TalentHub.

2. Vercel. *Next.js Documentation*. https://nextjs.org/docs — App Router, deploy frontend.

3. Prisma. *Prisma Docs*. https://www.prisma.io/docs — ORM MySQL, migrations.

4. IETF. *RFC 7519: JSON Web Token (JWT)*. https://datatracker.ietf.org/doc/html/rfc7519

5. Fielding, R. T. *Architectural Styles and the Design of Network-based Software Architectures* (REST). USC, 2000.

6. Google. *Gemini API for Developers*. https://ai.google.dev/

7. Cloudinary. *Documentation*. https://cloudinary.com/documentation — Upload authenticated, signed URLs.

8. VNPAY. *Tài liệu tích hợp cổng thanh toán* — Tài liệu merchant (không công bố khóa bí mật).

9. Socket.IO. *Documentation*. https://socket.io/docs/v4/

10. Trường ĐH Văn Lang — Khoa CNTT. *Hướng dẫn trình bày Chuyên đề tốt nghiệp 2* (PDF template 2026).

11. TalentHub Repository. `docs/SETUP.md`, `docs/IMPLEMENTATION_PLAN.md` — Tài liệu nội bộ dự án.
